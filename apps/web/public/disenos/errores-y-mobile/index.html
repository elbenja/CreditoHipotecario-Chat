Estados de error

Cinco fallas, cinco tratamientos distintos. La regla que las ordena: el error nunca borra lo que el usuario ya tenía. El panel de datos y el historial siguen ahí, intactos, en los cinco casos — solo cambia el último turno. Y ninguno usa rojo salvo el que de verdad es un fallo del sistema: rojo en una app de plata se lee como "perdiste dinero", no como "reintenta".
